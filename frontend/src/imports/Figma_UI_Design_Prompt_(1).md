**Figma UI Design Prompt (Enhanced)**

Design a modern, clean, and engaging **mobile app UI (iOS style)** for a
college-focused voting engagement platform. The app should feel social,
gamified, and motivating, similar to fitness or social competition apps.

**Themes (Light & Dark Mode)**

Create both **Light Mode** and **Dark Mode** versions of all screens:

-   Ensure proper contrast and accessibility in both modes

-   Light Mode: white/light gray backgrounds, dark text

-   Dark Mode: deep gray/black backgrounds, light text

-   Use consistent color tokens (primary, secondary, accent, background,
    surface)

-   Party colors should adapt appropriately for both themes

**Typography System**

Use **two different sans-serif typefaces**:

-   **Header Typeface:** Bold, modern sans-serif (for titles and
    emphasis)

-   **Body Typeface:** Clean, highly readable sans-serif (for paragraphs
    and UI text)

Define a type scale:

-   H1, H2, H3 (headers)

-   Body (regular text)

-   Caption / small text

**Components Page (Design System)**

Include a dedicated **Components / Design System page** with reusable
elements:

**Colors:**

-   Primary, Secondary, Accent

-   Success, Warning, Error

-   Light & Dark theme variants

**Typography Styles:**

-   Header styles (H1--H3)

-   Body styles

-   Caption

**UI Components:**

-   Buttons (primary, secondary, disabled)

-   Cards (default, leaderboard, election, candidate)

-   Navigation bar (bottom tab bar)

-   Input fields (default, active, error)

-   Progress bars (for leaderboard stats)

-   Badges / stickers ("I Voted")

-   List items (for leaderboard and resources)

-   Icons set (simple, consistent style)

Use **Auto Layout** and consistent spacing (8pt grid system).

**Screens to Design**

**1. Home Tab**

-   "Welcome back, \[Username\]" header

-   Leaderboard preview card (top 3 colleges with progress bars)

-   Upcoming Elections section (card layout)

-   Candidate Info preview cards

-   Bottom navigation bar

**2. Profile Tab**

-   Profile picture (circular)

-   Username + college name

-   Stats:

    -   Vote count

    -   Year joined

-   "I Voted" badge/sticker display

-   Buttons:

    -   Edit Profile

    -   Share Profile

**3. Leaderboard Tab**

-   Title: "College Leaderboard"

-   Ranked list of colleges:

    -   College name

    -   Participation percentage

    -   Progress bar

    -   Party color indicator

-   Highlight top 3 visually (medals or emphasis)

**4. Resources Tab**

-   Scrollable cards:

    -   Candidate Information

    -   Upcoming Elections

    -   Campus Resources

    -   Polling Stations (map preview)

    -   "How to Vote" guide

**5. Security / Verification Tab**

-   "Verify Your Vote" title

-   Input key field

-   Location confirmation indicator

-   Success state showing digital "I Voted" sticker

**Design Style**

-   Clean, minimal, modern

-   Rounded corners and soft shadows

-   Bright, motivating color palette

-   Gamification elements (badges, rankings, progress bars)

-   Accessible and readable in both light and dark modes

**Extras**

-   Include micro-interactions (pressed states, transitions)

-   Use consistent spacing and layout hierarchy

-   Ensure all components are reusable and scalable
